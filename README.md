# hldo.com.br

Site institucional da HLDO Tech (HLDO TECNOLOGIA DA INFORMACAO LTDA), publicado pelo
GitHub Pages em https://hldo.com.br. HTML estático, sem build: `index.html` (pt-BR),
`en/index.html` (inglês) e `assets/`.

Pré-visualizar: `python3 -m http.server 8790` e abrir http://127.0.0.1:8790/.
